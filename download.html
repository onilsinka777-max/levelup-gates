КАК УСТАНОВИТЬ

  1. Android — открой скачанный файл и разреши установку из этого источника (браузер спросит один раз). Нужен Android 8 или новее.
  2. Windows — распакуй архив и запусти LevelUp.exe. Если Windows предупредит — «Подробнее» → «Выполнить в любом случае».
  3. Mac — распакуй архив, затем правый клик по LevelUp.app → «Открыть» → «Открыть».
  4. iPhone — открой «iPhone» в Safari, затем «Поделиться» → «На экран «Домой»» — игра откроется во весь экран. Первый запуск — около минуты (скачивается ~120 МБ), дальше быстрее.

ПРОГРЕСС

  1. Прогресс хранится на сервере игры — переходи между устройствами и потом в версию из магазина без потерь.
  2. Войди по почте (Меню → «Войти по почте») — один прогресс на телефоне и компьютере.
  3. Играл в веб-версию? На первом экране — «Уже играл? Вернуть прогресс».
  4. Играл на levelupp.ru? Бот в Telegram пришлёт код переноса — введи его в «Аккаунт».
